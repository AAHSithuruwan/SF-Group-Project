🚀 Overview:**

Mobile Planet is a sleek and secure mobile phone e-commerce platform built for a seamless user experience. 🛒 It features:

- 🔐 **Secure User Authentication** – with password hashing & session management  
- 👤 **User-Friendly Profiles** – allowing sign-up, login, and profile updates  
- 🔍 **Smart Search & Categorization** – fast keyword-based queries and product filtering  
- 💡 **Responsive Design** – powered by Bootstrap for mobile-first browsing

This project demonstrates practical skills in full-stack web development, secure data handling, and intuitive UI/UX design, making it a robust example of a modern, secure shopping interface.
